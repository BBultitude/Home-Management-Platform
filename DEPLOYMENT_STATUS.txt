MAINTENANCE COMMANDS
================================================================================

View logs:
  docker logs homemanager_frontend_prod
  docker logs homemanager_backend_prod
  docker logs homemanager_db_prod

Restart containers:
  docker compose -f docker-compose.prod.yml restart

Stop deployment:
  docker compose -f docker-compose.prod.yml down

Start deployment:
  docker compose -f docker-compose.prod.yml up -d

View container stats:
  docker stats homemanager_frontend_prod homemanager_backend_prod homemanager_db_prod

Database backup:
  docker exec homemanager_db_prod pg_dump -U homeuser homedb > backup_$(date +%Y%m%d).sql

Database restore:
  cat backup.sql | docker exec -i homemanager_db_prod psql -U homeuser homedb

================================================================================
TROUBLESHOOTING
================================================================================

If login fails:
  1. Check backend logs: docker logs homemanager_backend_prod
  2. Verify database connection: docker exec homemanager_backend_prod curl http://localhost:8000/health
  3. Check nginx proxy: docker logs homemanager_frontend_prod

If containers crash:
  1. Check resources: docker stats
  2. Review logs for errors
  3. Verify secrets exist: ls -la secrets/
  4. Restart: docker compose -f docker-compose.prod.yml restart

If database issues:
  1. Check migrations: docker exec homemanager_backend_prod alembic current
  2. Check connection: docker exec homemanager_db_prod pg_isready -U homeuser
  3. Review logs: docker logs homemanager_db_prod
